# KankanBan 0.0.0.1 · Windows 测试版

首个供朋友试用的公开预发布版本，目前仍在持续完善。

## 下载与安装

下载 `KankanBan_0.0.0.1_windows_x64-setup.exe`，运行安装程序。适用于 Windows 10／11 的 x64 电脑，本版不提供 ARM64 或其它系统的安装包。

无需安装 Node.js 或 Rust。系统缺少 WebView2 时，安装程序会联网下载所需运行时。此测试包未进行代码签名，Windows 可能显示未知发布者或 SmartScreen 提示；请核对下载来源与附带的 SHA-256。

新工作区会自动展开中文新手教程，包含 11 个章节与可操作的练习卡。设置中的“回顾新手教程”可以再次打开；重复打开保留练习修改。教程第 10 章也介绍了回顾入口和重新生成的方法。

## 可以试试

- 新建卡片，分别编辑标题与正文，添加子卡并使用面包屑返回。
- 在桌面展开卡片，移动、吸附、折叠、置顶和调整窗口尺寸。
- 尝试看板、瀑布流和可平移缩放的灵感台。
- 创建预制体实例，修改后使用面包屑右侧同步按钮。
- 用铅笔／橡皮在正文或灵感台上涂鸦：右键绘制或擦除，左键退出。
- 点击管理器的工作区完整路径，选择自己的存档文件夹；右侧 × 返回默认工作区，原数据保留。

关闭管理器会保存并退出应用。数据保存在工作区的 `.kkb` 中，外部 Git 使用的 `.gitignore` 在工作区根目录。建议先用单独的测试文件夹，不混入重要数据。

## 测试反馈

请记录 Windows 版本、显示缩放比例、复现步骤、预期与实际表现；有错误时附上文字或截图。重点关注保存与重开、连续拖动、工作区切换、涂鸦持久化，以及不同窗口大小下的布局。

当前桌面应用与 CLI／MCP 不能同时写入同一工作区。安装、启动、跨窗口手势及真实多屏行为仍需人工验收；构建成功不代表这些操作已经实测通过。

## 版本与回退

对外版本和 Windows 数字版本为 `0.0.0.1`；Tauri／Cargo／npm 内部使用等价构建编号 `0.0.0+1`。本版只更新构建版本与安装配置，不引入新的数据迁移。

卸载应用不会主动删除用户自行选择的工作区。回退前先退出应用并备份整个 `.kkb` 目录，不要让多个版本同时写入同一份存档。
