# KankanBan

把便签、看板和灵感画布放进同一棵卡片树。

KankanBan 是一个基于 **Tauri 2、React 和 TypeScript** 的本地桌面应用。卡片既能作为桌面上的独立窗口，也能成为另一张卡片的子卡；标题、Markdown 正文、涂鸦和子卡结构一起保存。你可以用它整理任务、拆解想法，或把零散内容铺在灵感台上。

目前处于第一轮迭代后的持续完善阶段，主要开发与使用环境为 Windows。

## 已有功能

- **卡片树与桌面窗口**：任意层级的子卡、面包屑导航、独立展开、窗口置顶与折叠、边缘吸附、自定义尺寸调整。
- **多种排列**：底部横排、右侧竖列、瀑布流、固定三列看板，以及二维循环平铺的灵感台。瀑布流卡片保持最小宽度，最大高度为最小高度的两倍。
- **灵感台**：平移、滚轮平滑缩放、卡片位置编辑；左键、右键、中键／左右双键的拖动行为可在设置中分别配置。
- **预制体与实例**：复制整棵子树，区分本体与实例配色；手动同步正文、子卡结构、布局和涂鸦。同步入口位于面包屑右侧。
- **随手涂鸦**：正文上方的透明笔迹层随内容滚动；铅笔与橡皮两个工具，右键绘制／整笔擦除。灵感台上的相交笔迹与卡片按组保持相对位置。
- **本地工作区**：选择个人文件夹作为存档位置，保存后直接切换并重新加载界面；支持返回默认工作区。
- **白天与黑夜皮肤**：共享配色表，支持调整卡片圆角；程序文案集中管理，为后续多语言适配保留入口。
- **撤销与持久化**：卡片事件日志、事务保存、窗口状态恢复，以及桌面／CLI／MCP 共用的写者锁。

## 从源码运行

准备 Node.js 22.6 或更新版本、Rust 工具链，以及 Tauri Windows 开发环境（MSVC C++ 构建工具与 WebView2）。

```powershell
git clone https://github.com/srtan9er/kankanban.git
cd kankanban/KankanBan
npm ci
npm run app
```

`npm run app` 启动完整桌面应用。开发服务器使用 `5183` 端口，并能识别、复用本项目已经运行的 Vite 服务。

其他常用命令均在 `KankanBan/` 中执行：

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 浏览器预览，数据独立于桌面工作区 |
| `npm run typecheck` | TypeScript 类型检查 |
| `cargo check --manifest-path src-tauri/Cargo.toml` | Rust 编译检查 |
| `npm test` | 运行现有测试集 |
| `npm run app:build` | 构建桌面发行包 |
| `npm run app:build -- --no-bundle` | 只构建可执行程序 |
| `npm run cli -- --help` | 查看 CLI 帮助 |

浏览器预览不能代替桌面窗口、跨窗口拖放和多屏交互的验证。

## 基本操作

| 操作 | 行为 |
| --- | --- |
| 管理器中双击卡片 | 在桌面展开；已展开的窗口置顶并获得焦点 |
| 卡片窗口中双击子卡 | 进入该子卡，使用面包屑或 ← 返回 |
| 单击标题或正文 | 编辑对应字段；左键按下编辑框外的区域时保存并退出 |
| 拖动普通窗口的非按钮、非子卡区域 | 移动窗口，进入拖动前保持默认光标 |
| 拖动窗口左上角灰色抓手 | 改变卡片的树上归属；失败时保持原位置 |
| 拖动右下角方块 | 调整窗口大小 |
| 子卡垃圾桶 | 确认后删除该卡片及其全部子卡 |
| 点击铅笔／橡皮胶囊 | 进入或切换绘图模式，再次点击当前工具退出 |
| 绘图模式下右键拖动 | 绘制或擦除；左键按下退出绘图 |
| 点击管理器中的完整工作区路径 | 选择并切换存档文件夹；右侧 × 返回默认工作区 |

正文仅在绘图模式下允许持续向下扩展空白，绘图期间不收缩；退出后收回多余空白，保留正文与笔迹。灵感台滚轮始终用于缩放。

关闭卡片窗口只收起它，**关闭卡片管理器会保存并退出整个应用**。

## 数据存放

默认工作区位于应用数据目录，也可以使用自己的文件夹。管理器会显示实际的完整路径。

```text
你的工作区/
├─ .gitignore                 # 供外部 Git 使用，默认忽略 .kkb/
└─ .kkb/
   ├─ cards/                  # 卡片 Markdown、字段与涂鸦
   ├─ tree.json               # 卡片树结构
   ├─ events.jsonl            # 操作日志
   ├─ view-state.json         # 界面设置与视图状态
   ├─ window-prefs.json       # 原生窗口位置与尺寸
   ├─ writer.lock/            # 活跃写者锁
   └─ backups/                # 应用备份
```

切换或返回默认工作区不会删除原目录的数据。备份工作区时，先退出应用及其他写者，再复制整个 `.kkb` 目录。

当前桌面应用、CLI 与 MCP 采用互斥写者机制，不能同时写入同一工作区。Git 面板仅显示状态与最近提交，不负责提交、推送或卡片数据同步。

## 接下来的更新计划

以下按优先顺序安排，属于规划，不代表已实现；具体范围会根据实际使用反馈调整。

### 1. 稳定性与交互收尾

- 集中处理工作区切换、保存失败、异常退出与连续拖动的问题。
- 梳理普通卡片、管理器、看板与灵感台的公共交互，减少行为差异。
- 完善不同窗口尺寸、显示缩放和多屏情况下的布局与命中区域。
- 优化大卡片树、循环画布与大量笔迹的响应速度。

### 2. 数据保护与可携带性

- 提供明确的备份、恢复和导入／导出入口。
- 改善工作区损坏、写者锁冲突和磁盘写入失败时的提示与恢复流程。
- 让卡片内容与结构更容易在不同电脑之间搬运。

### 3. 整理与检索效率

- 增加跨卡片搜索与快速定位。
- 补齐常用键盘操作、焦点导航和批量整理能力。
- 改善长正文与涂鸦混合内容的编辑体验。

### 4. 预制体与个性化

- 展示预制体／实例的未同步修改，并提供同步前差异预览。
- 明确结构修改和局部覆盖冲突的处理方式。
- 增加皮肤配置的导入／导出，并在现有文本表上扩展语言支持。

### 5. 发布与外部工具接入

- 整理安装包、版本说明和升级流程。
- 完善 CLI／MCP 使用文档；评估统一写入服务，使外部工具与桌面应用能够安全协作。
